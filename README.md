Tears of the Kingdom 1.2.1 Save Converter is a tool I created to make working with The Legend of Zelda: Tears of the Kingdom save files easier, particularly when moving saves between the normal progress.sav format and the .ktml format used by Zonai Hosting.

Why I Made This

I originally started this project because I ran into a problem myself. I wanted to edit my Tears of the Kingdom saves, and continue playing the game the way I wanted too but i ran into a problem the save format from Zonai Hosting For Tears Of The Kingdom Multiplayer Only Reads .ktml Formats and the Save Editior Reads progress.sav So I Went Ahead An Made Tears Of The kingdom Save Convertor, so now i can experiment with my save data, and simply have more fun with the game.

The problem was that I couldn't find a converter that did what I needed.

I had a normal progress.sav, while Zonai Hosting worked with .ktml save files. I searched for a way to convert between these formats but couldn't find an existing tool that solved the problem for me.

So instead of giving up on it, I decided to make one.

My goal was to create something that wasn't just useful for me, but could eventually help other Tears of the Kingdom players who run into the same problem.

What the Converter Does

The converter provides two conversion directions:

.ktml → progress.sav

This allows a Zonai Hosting .ktml save to be converted back into a normal Tears of the Kingdom progress.sav using a compatible save template.

progress.sav → .ktml

This allows a normal Tears of the Kingdom progress.sav to be converted into the .ktml structure used by Zonai Hosting. A compatible .ktml template is required because the binary save stores hashed identifiers rather than all of the original readable KTML variable names and type information.

Designed to Be Easy to Use

I wanted the program to feel like an actual application instead of just a conversion script. It includes a dark Zelda-inspired interface, a transparent Triforce design, separate conversion tabs, status information, and Zelda-themed sound effects for successful conversions, failed conversions, and warning messages.

I also intentionally organized the source code so other people can customize it. The download includes step-by-step .TXT guides explaining how to change the colors, text, sounds, icons, application name, and other parts of the interface using programs such as Notepad++ or Visual Studio Code.

This project isn't about taking the fun out of Tears of the Kingdom. For me, it was the opposite.

I wanted more freedom with my own saves so I could experiment, continue my adventures, edit things when I wanted to, and get even more enjoyment out of a game I already love.

If this converter helps somebody else who was searching for the same thing I was, then creating it was worth it.
